# EV Charging Information Website

A simple and responsive website that provides information about Electric Vehicle (EV) charging, types of chargers, and their benefits.

### Features
- Information about EV charging
- AC and DC charger details
- EV charging time calculator
- Dark and Light mode
- Contact page

### Technologies
HTML, CSS, JavaScript

### Project Objective
To create awareness about electric vehicle charging and help users understand different charging options.

### How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run `index.html` in your web browser.
